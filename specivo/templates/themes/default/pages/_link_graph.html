{# The link graph view: the Graph tab of an issue, the Graph block of a wiki page and the project's Graph page. link_graph(endpoint, scope, testid, opened) renders the controls, the drawing area and an item list; the graph itself is drawn by link-graph.min.js (Apache ECharts), which only the graph views load. The data comes from the link graph JSON (endpoint: /api/v1/issues//links/, /api/v1/projects//wiki//links/ or /api/v1/projects//links/); hub nodes are expanded through /api/v1/links/?ref=. - scope: "item" (an issue or a page: two hops) or "project" (no root, one hop from the most linked items). - opened: true when the graph is drawn on load (the project page); otherwise the tab or block that holds it sets data-sp-graph-open when it is first opened (modules/link-graph-loader.js), which loads the bundle.
