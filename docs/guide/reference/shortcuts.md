# Keyboard shortcuts

Specivo keeps keyboard shortcuts minimal and predictable. This page lists the shortcuts available today.

## Search from anywhere

Press <kbd>⌘K</kbd> (on macOS) or <kbd>Ctrl+K</kbd> (on Windows/Linux) anywhere in the app to jump straight
to the search box and start typing. You don't need to reach for the mouse or scroll back to the top of the
page.

| Shortcut | Action |
|---|---|
| <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd> | Focus the search box from any page |

See [Finding issues](../issues/finding.md) for what you can do once search has focus.

!!! note "More may be added"
    The shortcut list is intentionally short for now. Additional shortcuts may be introduced in later
    releases; this page will be updated when they are.
