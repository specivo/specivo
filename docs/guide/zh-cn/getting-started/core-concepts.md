# 核心概念 {#core-concepts}

Specivo 的词汇不多，而且前后一致。记住这八个词，指南的其余部分就很容易读懂。

## 项目 {#project}

**项目** 是一组工作的容器。每个项目都有一个 **标识**：像 `ACME` 这样的大写短前缀，项目里每个工作项的编号都以它开头（例如 `ACME-42`）。项目包含工作项、维基、版本、冲刺，以及带角色的成员列表。项目可以嵌套。参见 [项目](../projects/index.md)。

## 工作项 {#issue}

**工作项**（Issue）是工作的基本单位：可以是一个缺陷、一项功能、一个任务，或一个支持请求。它有主题、描述，以及负责人、优先级、截止日期等字段。工作项按项目分别编号（`ACME-1`、`ACME-2`……）。参见 [工作项](../issues/index.md)。

## 追踪器 {#tracker}

**追踪器**（Tracker）是工作项的*类型*。Specivo 自带四种：**Bug**（缺陷）、**Feature**（功能）、**Task**（任务）和 **Support**（支持）。追踪器决定工作项适用哪些字段和工作流，还可以让自己的新建工作项[默认设为私有](../issues/creating.md#private-by-default)。参见 [什么是工作项？](../issues/index.md)。

## 状态 {#status}

**状态** 表示工作项处于生命周期的哪个阶段。默认状态是 **New**（新建）→ **In Progress**（进行中）→ **Resolved**（已解决），另有 **Feedback**（待反馈）、**Closed**（已关闭）和 **Rejected**（已拒绝）。每个状态都归属一个类别（待办、进行中、已完成、已关闭），看板和报表都基于这些类别工作。参见 [状态与工作流](../issues/statuses-workflow.md)。

## 关联 {#relation}

**关联** 是两个工作项之间带类型的链接，例如*关联到*、*阻塞*、*重复于*、*先于*等。关联用来记录依赖关系和历史。参见 [关联](../issues/relations.md)。

## 版本 {#version}

**版本**（也叫里程碑或发布）把工作项归到同一个目标之下，例如 `v1.2`。**路线图** 由版本驱动。参见 [版本与路线图](../projects/versions.md)。

## 冲刺 {#sprint}

**冲刺**（Sprint）是一次有时间限制的迭代，有自己的待办列表和目标。冲刺先规划，再开始，最后完成；完成时 Specivo 会把团队当时的速率记录下来。参见 [冲刺](../projects/sprints.md)。

## 维基 {#wiki}

**维基**（Wiki）是项目的知识库：一组 Markdown 页面，带完整的版本历史、层级结构和页面间的交叉链接。参见 [维基与知识库](../wiki/index.md)。

## 元数据 {#metadata}

**元数据** 是附加在工作项核心字段之外的结构化、带类型的数据，例如故事点、git 分支、严重级别。元数据由 **架构** 定义，这样同一字段在所有工作项上都保持一致。参见 [工作项元数据](../metadata/index.md)。

---

!!! tip "一个概念，一个词"
    Specivo 始终使用 **工作项**（不说“工单”或“任务项”）、**维基页面**、**版本** 和 **冲刺** 这几个词。在文档或应用里搜索时，用这些词就对了。完整列表见[术语表](../reference/glossary.md)。
