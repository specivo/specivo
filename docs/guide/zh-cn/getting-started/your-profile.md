# 个人资料 {#your-profile}

从账户菜单（页头中的头像和姓名）打开 **个人资料**。这里显示你的显示名称、登录名、电子邮件地址、语言、时区，以及上次登录时间。你可以在此修改显示名称、头像和电子邮件地址。语言、时区和会话在 **偏好设置** 中管理。

个人资料页还链接到 **我的 AI 订阅**，用于记录你付费的固定价格 AI 套餐，例如 Claude Max 或 ChatGPT Plus；参见 [AI 订阅](../install/ai-subscriptions.md)。

## 更改电子邮件地址 {#changing-your-email-address}

Specivo 会把登录帮助、密码重置链接和通知发送到你的电子邮件地址，并用它来匹配已连接仓库中的提交。因此，新地址只有在你证明能收到发往该地址的邮件后才会生效。

1. 在 **电子邮件地址** 下输入新地址和当前密码，然后选择 **更改电子邮件**。
2. Specivo 会向新地址发送一个链接。在你打开链接之前，账户继续使用旧地址：登录、重置密码和接收通知都仍通过旧地址进行。
3. 打开链接并选择 **确认电子邮件地址**。链接打开的是一个带有该按钮的页面，而不是直接完成更改，这样自动打开链接的邮件扫描器就不会误用它。确认时无需登录，在任何浏览器中都可以操作。

链接 24 小时内有效，且只能使用一次。更改完成后：

- 旧地址会收到一封邮件，告知地址已被更改（新地址部分隐藏），并附带密码重置链接以及“如果不是你本人操作，请联系管理员”的提示；
- 该账户的其他所有会话都会被退出登录；你用来确认的浏览器如果登录的是同一账户，则保持登录状态；
- 更改前发出的密码重置链接全部失效；
- 这次更改会记录到[安全审计日志](../install/audit-log.md)中。

### 更改待确认期间 {#while-a-change-is-pending}

个人资料页会显示 **更改为 new@example.com 待确认**，并提供两个按钮：

- **重新发送链接**：发送一个新链接。只有最新的链接有效，之前的链接随即失效。
- **取消更改**：终止此次请求，其链接失效。

再次发起更改也会替换掉待确认的那一次。如果链接已过期，个人资料页会给出提示，点击 **重新发送链接** 即可获得新链接。

如果你输入的地址已被其他账户使用，你看到的仍是同样的“请查收邮件”提示和同样的待确认状态，因此页面不会泄露哪些地址已被占用。此时不会发送链接，而是通知该地址的所有者有人尝试使用它。如果在你打开链接之前有账户抢先使用了该地址，确认会失败，你的地址保持不变。

更改请求有频率限制：对你的账户和每个地址，每小时只允许少量几次。

### 通过单点登录的账户 {#accounts-that-sign-in-through-single-sign-on}

如果你通过组织的[身份提供商](../install/single-sign-on/index.md)登录，账户没有密码，也就无法用密码来确认更改。此时改为选择 **通过……重新登录**（后跟你的提供商名称）：它会要求你在提供商处重新登录一次，即使你在那里已处于登录状态。回到个人资料页后，你有五分钟时间发起更改。你必须以与个人资料关联的同一个提供商账户登录；以其他身份登录会被拒绝。

已连接的账户不会随电子邮件地址变化：Specivo 通过提供商自己的账户 ID 识别它们，而不是电子邮件。

### 地址由身份提供商管理时 {#when-the-address-is-managed-by-your-identity-provider}

如果你的组织通过身份提供商自动创建和更新账户（[SCIM](../install/single-sign-on/scim.md)），电子邮件地址就由提供商掌管。个人资料页只显示地址而不提供修改入口，并提示 **请在身份提供商处更改**；提供商下一次同步时会把新地址带到 Specivo。

## 管理员 {#administrators}

管理员可以在 **管理 → 用户 →** 具体用户的 **账户详情** 下更改任何人的地址，也可以调用 `PATCH /api/v1/admin/users/{id}/email/`（需要已登录的会话，API 密钥会被拒绝）。新地址立即生效并标记为已验证，无需确认链接。旧地址和新地址都会收到通知，更改也会记录到审计日志中。

## 通过 API {#through-the-api}

以该账户身份登录的 API 客户端也可以完成同样的步骤：

| 请求 | 作用 |
|---|---|
| `GET /api/v1/auth/me/email/` | 返回你的地址、待确认的更改（没有则为 `null`），以及当前是否可以发起更改。 |
| `POST /api/v1/auth/me/email/` | `{"new_email": "...", "current_password": "..."}`。返回 `202` 和待确认的更改。 |
| `POST /api/v1/auth/me/email/resend/` | 为待确认的更改发送新链接。 |
| `DELETE /api/v1/auth/me/email/` | 取消待确认的更改。 |
| `POST /api/v1/auth/confirm-email/` | `{"token": "..."}`，取自链接。无需登录。 |

此操作没有对应的 MCP 工具：更改账户地址只能由本人完成。
