# 界面导航 {#navigating-the-interface}

Specivo 的每个页面都有两个固定的导航区域：左侧的 **侧边栏** 用于在各处之间切换，顶部的 **页眉** 用于搜索和管理账户。

![Specivo 的侧边栏和页眉](../../assets/img/nav-sidebar.webp)

## 侧边栏（左侧） {#the-sidebar-left}

侧边栏是你在 Specivo 中移动的主要方式。从上到下依次是：

- **搜索**、**仪表盘**、**项目**：始终可用。
- **当前项目**：进入某个项目后，该项目的区域会列出 **工作项**、**待办列表**、
  **当前冲刺**、**维基**、**路线图**、**工时记录**、**冲刺** 和 **设置**。
- **管理**：一个 **管理员** 链接，只对管理员显示。

**工作项** 条目旁有一个徽标，显示该项目中未关闭的工作项（Issue）数量。要切换项目，点击
**项目** 后选择另一个，或直接使用侧边栏中的项目列表。

## 页眉（顶部） {#the-header-top}

横贯主区域顶部的是：

- **搜索框**：搜索工作项、维基和项目。在任何位置按 <kbd>⌘K</kbd>（Windows/Linux 上为
  <kbd>Ctrl+K</kbd>）即可直接跳入搜索。参见[查找工作项](../issues/finding.md)。
- **字号切换**：在三种文字大小之间切换，让阅读更舒适。
- **通知**：一个带未读徽标的铃铛图标；打开后可以看到最近的提及和更新，也可以
  **查看所有通知**。
- **账户菜单**：点击你的头像和姓名会打开一个菜单，包含 **个人资料**、**偏好设置**、
  **API 密钥**（用于 [MCP 服务器](../ai-agents/api-keys.md)和 REST API）以及 **退出登录**。
  **偏好设置** 中列出了你当前活跃的会话以及每个会话的登录方式。如果管理员已配置
  [单点登录](../install/single-sign-on/index.md)（SSO），**个人资料** 中会多出一个 **已关联账户** 区域；
  没有设置密码的账户在密码页面上没有可修改的内容。
  [个人资料](your-profile.md)一页介绍了如何修改邮箱地址。

!!! tip "正在计时"
    如果你在某个工作项上启动了工时计时器，页眉中会显示一个实时计时器，你可以在任何页面上停止计时并记录工时。参见[工时记录](../projects/time-tracking.md)。

## 在手机或平板上 {#on-a-phone-or-tablet}

Specivo 采用响应式布局。在窄屏幕上，侧边栏会收起到页眉的 **菜单按钮**（☰）后面，点击它即可滑出侧边栏。所有页面和操作都仍然可用，只是为了适应小屏幕而改为纵向堆叠。
