# 快捷键 {#keyboard-shortcuts}

Specivo 的快捷键（keyboard shortcut）力求精简、可预期。本页列出目前可用的快捷键。

## 随处搜索 {#search-from-anywhere}

在应用的任意位置按 <kbd>⌘K</kbd>（macOS）或 <kbd>Ctrl+K</kbd>（Windows/Linux），即可直接跳到搜索框开始输入，
不必去拿鼠标，也不用滚回页面顶部。

| 快捷键 | 操作 |
|---|---|
| <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd> | 在任意页面聚焦搜索框 |

搜索框获得焦点后能做什么，请参阅[查找工作项](../issues/finding.md)。

!!! note "后续可能增加"
    目前的快捷键列表有意保持精简。后续版本可能会引入更多快捷键，届时本页会同步更新。
