# 术语表 {#glossary}

Specivo 用到的每个术语，各用一句话定义。较复杂的术语附有完整说明页面的链接。

| 术语 | 定义 |
|---|---|
| **完成百分比** | 工作项的完成进度，取值 0–100。工作项进入 *done* 类状态时会自动设为 100，例如 **Resolved**（已解决）。参见 [状态与工作流](../issues/statuses-workflow.md)。 |
| **Agent**（代理，角色） | 面向 API 和自动化账户的成员角色，这些账户通过 [MCP 服务器](../ai-agents/index.md) 执行操作。 |
| **API 密钥** | 以 `spv_…` 开头的保密字符串，用于代表某个用户认证 REST 和 MCP 请求。参见 [API 密钥](../ai-agents/api-keys.md)。 |
| **附件** | 上传到工作项、维基页面或评论的文件，有自己的文件名、大小、类型和可搜索的描述。参见 [附件](../issues/attachments.md)。 |
| **待办列表** | 尚未排期的工作项池，团队规划冲刺时从中选取。参见 [冲刺](../projects/sprints.md)。 |
| **看板** | 按状态类别（待办 / 进行中 / 已完成 / 已关闭）分列展示工作项的视图。工作项和冲刺各有自己的看板。 |
| **类别** | 项目范围内用于归类工作项的标签，例如“后端”“前端”。请勿与状态类别混淆。 |
| **Developer**（开发者，角色） | 面向实际执行工作的人员的成员角色：可以创建和更新工作项，但不能管理项目设置。 |
| **工作项**（Issue） | 工作的基本单位：一个缺陷、功能、任务或支持请求，按项目独立编号。参见 [工作项](../issues/index.md)。 |
| **issue_ref** | 带项目前缀的工作项标识符，例如 `ACME-12`。用于链接中，AI 智能体（AI agent）也用它来指定具体的工作项。 |
| **Manager**（管理者，角色） | 拥有项目完全控制权的成员角色，包括设置、成员和元数据架构。 |
| **MCP 服务器** | Specivo 内置的 MCP（Model Context Protocol，模型上下文协议）服务器，让 AI 客户端读写 Specivo。参见 [AI 智能体](../ai-agents/index.md)。 |
| **元数据** | 工作项核心字段之外的带类型键值字段，由元数据架构定义。参见 [工作项元数据](../metadata/index.md)。 |
| **元数据架构** | 基于 JSON Schema 的定义，规定哪些元数据字段适用于某个项目或追踪器。参见 [元数据架构](../metadata/schemas.md)。 |
| **优先级** | 工作项的紧急程度：**Low**（低）、**Normal**（普通，默认值）、**High**（高）、**Urgent**（紧急）或 **Immediate**（立即）。 |
| **默认私有** | **管理 → 追踪器**下的追踪器设置：该追踪器新建的工作项一开始就是私有的。参见 [默认私有](../issues/creating.md#private-by-default)。 |
| **项目** | 承载一组工作的容器：工作项、维基、版本、冲刺和成员。参见 [项目](../projects/index.md)。 |
| **项目标识** | 项目中每个工作项编号的简短大写前缀，例如 `ACME`（对应 `ACME-1`）。 |
| **关联** | 两个工作项之间带类型的链接：关联到、阻塞、重复于、先于或复制到。参见 [关联](../issues/relations.md)。 |
| **Reporter**（报告者，角色） | 成员角色之一，适用于提交工作项、发表评论但不承担具体工作的人员。 |
| **路线图** | 展示各版本及其进度的项目视图。参见 [版本与路线图](../projects/versions.md)。 |
| **slug** | 维基页面标题规范化后的 URL 形式；`My Page`、`my-page` 和 `My_Page` 都解析为同一个 slug。参见 [链接与历史](../wiki/history-linking.md)。 |
| **冲刺**（Sprint） | 有固定时间范围的迭代，包含目标、开始和结束日期以及独立的看板。参见 [冲刺](../projects/sprints.md)。 |
| **状态** | 工作项在生命周期中所处的位置：**New**（新建）、**In Progress**（进行中）、**Resolved**、**Feedback**（待反馈）、**Closed**（已关闭）、**Rejected**（已拒绝）。参见 [状态与工作流](../issues/statuses-workflow.md)。 |
| **子工作项** | 嵌套在父工作项之下的工作项（最多 16 层）。参见 [子工作项](../issues/subtasks.md)。 |
| **工时记录可见性** | **管理 → 角色**下的角色设置：可以查看项目中**全部**工时记录，或只能查看**自己的**。参见 [工时记录](../projects/time-tracking.md#who-can-do-what)。 |
| **追踪器**（Tracker） | 工作项的*类型*：**Bug**（缺陷）、**Feature**（功能）、**Task**（任务）或 **Support**（支持）。参见 [工作项](../issues/index.md)。 |
| **用户可见性** | **管理 → 角色**下的角色设置：可以查找**所有活跃用户**，或只能查找你有权打开的项目中的成员。参见 [角色能看到什么](../projects/index.md#what-a-role-can-see)。 |
| **版本** | 将工作项归集到某个目标日期的里程碑或发布。参见 [版本与路线图](../projects/versions.md)。 |
| **关注者** | 关注某个工作项以接收其变更通知的用户。看不到该工作项的关注者（工作项被设为私有，或他们失去了项目访问权限）仍留在关注者列表中，但在恢复访问权限之前不会收到通知。 |
| **维基**（Wiki） | 项目的 Markdown 知识库，支持版本历史、页面嵌套和交叉链接。参见 [维基](../wiki/index.md)。 |
