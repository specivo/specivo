# 标签 {#tags}

**标签** 是附加在工作项（Issue）和维基（Wiki）页面上的简短彩色标记，用于在内置的追踪器（Tracker）、状态、优先级字段之外对工作进一步分类。标签在项目内定义一次，之后可以应用到该项目中任意数量的工作项或维基页面。

<!-- screenshot: tags in project settings -->

## 标签与元数据的区别 {#tags-vs-metadata}

标签和[元数据](../metadata/index.md)是两个独立的功能，用途不同：

| | 标签 | 元数据 |
|---|---|---|
| **形式** | 简单的命名标记（可选颜色） | 带架构的结构化键值字段 |
| **适用场景** | 快速分类标记（如“backend”、“needs-review”） | 有类型的数据字段（如分支名、环境、故事点） |
| **可应用于** | 工作项和维基页面 | 工作项 |
| **由谁管理** | 项目 **Manager**（项目经理）维护词表；任何成员均可应用 | 架构所有者 |
| **可筛选** | 可以，搜索页面提供跨项目标签筛选 | 可以，通过元数据包含筛选 |

只需要简单标记时，用标签；需要带类型和架构的结构化字段时，用元数据。

## 管理标签词表 {#managing-the-tag-vocabulary}

标签的创建、重命名、改色和删除都在 **项目设置** 的 **标签** 选项卡中完成。这里还会显示每个标签当前被多少个工作项和维基页面使用，方便你放心清理不再使用的标签。

<!-- screenshot: tag vocabulary in project settings tabs -->

!!! note "仅限 Manager"
    只有项目的 **Manager** 角色（以及管理员）可以创建、重命名、改色或删除标签。任何项目成员都可以在编辑工作项或维基页面时应用已有标签，也可以即时创建新标签。

### 创建标签 {#creating-a-tag}

1. 打开项目的 **设置**，点击 **标签** 选项卡。
2. 点击 **新建标签**。
3. 输入 **名称**（最多 64 个字符）。
4. 可选：在十六进制颜色字段中指定 **颜色**（例如 `#4f9d6c`）。标签出现在任何地方时，标签块上的色块都会使用这个颜色。
5. 点击 **创建标签**。

标签名称在项目内 **唯一且不区分大小写**：不能同时存在 `Backend` 和 `backend`，二者会被视为同一个名称。

### 重命名和修改颜色 {#renaming-and-recoloring-a-tag}

在标签选项卡中点击标签旁的编辑图标，修改名称或颜色（或两者都改），然后点击 **保存更改**。所有显示该标签的地方会立即更新，无需重新附加。

### 删除标签 {#deleting-a-tag}

点击标签的删除图标并确认。删除标签会把它从 **所有** 应用过它的工作项和维基页面上移除。此操作无法撤销。

!!! warning "删除会在所有位置移除标签"
    如果一个标签应用在 40 个工作项和 10 个维基页面上，删除它会一次性从这 50 个对象上解除。删除前请先查看标签选项卡中的使用计数。

## 给工作项打标签 {#tagging-issues}

标签显示在工作项侧边栏中。**查看** 或 **编辑** 工作项时都可以添加和移除标签。

<!-- screenshot: tag chips on an issue sidebar -->

要应用标签，在工作项侧边栏的 **添加标签** 字段中输入。输入时会弹出自动补全列表，列出项目中匹配的标签，选中一个即可应用。如果输入的名称尚不存在，它会被 **即时创建** 到项目的标签词表中，无需先在设置里预先建好。

要从工作项上移除标签，点击标签块上的移除按钮。

!!! tip "即时创建标签"
    任何成员都可以在标签输入框中输入新名称，标签会自动创建。新标签会立即出现在项目设置 → 标签中，Manager 之后可以重命名、改色或删除它。

## 给维基页面打标签 {#tagging-wiki-pages}

标签在维基页面上的用法相同。查看或编辑维基页面时，页面内容下方会出现一个 **标签字段**，在那里添加和移除标签，操作和工作项一样。

<!-- screenshot: tag field on a wiki page -->

附加到维基页面的标签会以可点击标签块的形式显示在页面上，与作者和最后编辑信息并列。

## 点击标签块 {#clicking-a-tag-chip}

每个标签块都是一个 **链接**。点击后会打开[搜索页面](../issues/finding.md#search)，并预先筛选出你有权访问的所有项目中带有该标签的全部工作项和维基页面。这是从一个对象跳到所有同标签内容最快的方式。

链接目标是 `/search/?scope=all&tag=<tag-name>`，可以收藏这些 URL。

## 在搜索中按标签筛选 {#filtering-by-tags-in-search}

搜索页面有专门的 **按标签筛选** 控件，与文本搜索框分开。

<!-- screenshot: tag filter on the search page -->

可以同时按多个标签筛选。选择多个标签时，结果采用 **AND 逻辑**：只返回带有 **全部** 所选标签的对象。

主要行为：

- **跨项目**：筛选范围覆盖你能访问的每个项目（成员项目或公开项目），不限于当前项目。你不是成员的私有项目中的标签不会包含在内。
- **不区分大小写**：输入 `backend` 会匹配名为 `Backend` 的标签。
- **自动补全**：输入时会提示你可访问项目中的标签名称，并显示已设置的颜色。
- **可与文本查询组合**：文本搜索词和标签筛选可以同时使用，结果必须同时满足两者。
- **无需文本查询**：只按标签筛选（不输入搜索词）时，列出所有匹配的对象，按最近更新时间排序。
- **同时覆盖工作项和维基页面**：无论当前激活的是哪个范围选项卡，标签筛选都会同时搜索两者（切换到“仅维基”范围选项卡时只显示匹配的维基结果，其他类似）。

### 移除标签筛选 {#removing-a-tag-filter}

点击筛选栏中标签块上的移除按钮即可取消选择该标签，页面会按剩余筛选条件重新加载。

## AI 智能体与标签 {#ai-agents-and-tags}

如果你通过 MCP 让 AI 智能体（AI agent）使用 Specivo，智能体也拥有同样的打标签能力。它可以：

- 列出项目的标签词表（含使用计数）。
- 在工作项或维基页面上添加、移除或整体替换标签集合，也可以在创建工作项或维基页面的同一步骤中打上标签。
- 在应用标签时即时创建标签（受成员项目角色限制）。
- 维护标签（创建、重命名、改色、删除），前提是账户拥有 `manage_project` 权限。

MCP 工具 `specivo_tag` 接受一个工作项引用（例如 `ACME-42`）或维基引用（`wiki:ACME/some-slug`）、一个操作（`get`、`add`、`remove`、`set`），以及一个标签名称或名称列表。智能体最先读取的设置指南会告诉它们：添加标签前先检查已有标签，并且绝不要把标签写进描述或页面正文。完整的工具目录见[智能体能做什么](../ai-agents/capabilities.md)。
