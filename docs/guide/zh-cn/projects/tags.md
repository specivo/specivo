# 标签 {#tags}

**标签** 是带颜色的简短标记，可以添加到工作项（Issue）和维基（Wiki）页面上，在内置的追踪器（Tracker）、状态和优先级字段之外为工作分类。标签在项目内定义一次，之后可以用于该项目中任意数量的工作项或维基页面。

<!-- screenshot: tags in project settings -->

## 标签与元数据的区别 {#tags-vs-metadata}

标签和[元数据](../metadata/index.md)是两个独立的功能，用途不同：

| | 标签 | 元数据 |
|---|---|---|
| **形式** | 普通的命名标记（可选颜色） | 带架构的结构化键值字段 |
| **最适合** | 快速分类标记（例如“backend”“needs-review”） | 有类型的数据字段（例如分支名、环境、故事点） |
| **适用对象** | 工作项和维基页面 | 工作项 |
| **由谁管理** | 项目 **Manager**（经理）管理标签库；能编辑该工作项或维基页面的成员负责添加 | 架构所有者 |
| **可筛选** | 可以：搜索页面的跨项目标签筛选 | 可以：元数据包含筛选 |

只需要一个简单的标记，就用标签。需要带类型和架构的结构化字段，就用元数据。

## 管理标签库 {#managing-the-tag-vocabulary}

标签的创建、重命名、改色和删除都在 **项目设置** 的 **标签** 选项卡中完成。这里还会显示每个标签当前用在多少个工作项和维基页面上，方便你放心清理不再使用的标签。

<!-- screenshot: tag vocabulary in project settings tabs -->

!!! note "仅限 Manager"
    只有项目 **Manager**（以及管理员）可以在项目设置中创建、重命名、改色或删除标签。添加标签属于编辑操作：角色有权编辑工作项（或管理维基页面）的成员可以添加已有标签，也可以随手创建新标签。只有查看权限的成员能看到标签，但不能修改。凡是能创建工作项的人，都可以在 **新建工作项** 表单中为新工作项设置标签。

### 创建标签 {#creating-a-tag}

1. 打开项目的 **设置**，点击 **标签** 选项卡。
2. 点击 **新建标签**。
3. 输入 **名称**（最多 64 个字符）。
4. 如有需要，在十六进制颜色字段中选择 **颜色**（例如 `#4f9d6c`）。无论标签出现在哪里，标签块上的色块都使用这个颜色。
5. 点击 **创建标签**。

标签名称在项目内 **不区分大小写且唯一**：`Backend` 和 `backend` 不能同时存在，它们会被视为同一个名称。

### 重命名标签和修改颜色 {#renaming-and-recoloring-a-tag}

在标签选项卡中点击任意标签旁的编辑图标。修改名称、颜色或两者，然后点击 **保存更改**。所有显示该标签的位置会立即更新，无需重新添加。

### 删除标签 {#deleting-a-tag}

点击标签的删除图标并确认。删除标签会把它从 **所有** 用到它的工作项和维基页面上移除。此操作无法撤销。

!!! warning "删除会在所有位置移除该标签"
    如果一个标签用在 40 个工作项和 10 个维基页面上，删除它会一次性从这 50 处全部移除。删除前请先在标签选项卡中查看使用数量。

## 为工作项添加标签 {#tagging-issues}

标签显示在工作项的侧边栏中。**查看** 或 **编辑** 工作项时都可以添加和移除标签。

<!-- screenshot: tag chips on an issue sidebar -->

要添加标签，在工作项侧边栏的 **添加标签** 字段中输入。输入时会出现自动补全列表，显示项目中匹配的标签，选择其中一个即可添加。如果输入的名称还不存在，系统会在项目的标签库中 **随手创建** 这个标签，所以不必事先在设置中准备好。

要从工作项上移除标签，点击标签块上的移除按钮。

!!! tip "随手创建标签"
    任何能编辑该工作项的成员都可以在标签输入框中输入新名称，标签会自动创建。新标签会立即出现在项目设置 → 标签中，之后 Manager 可以重命名、改色或移除它。

## 为维基页面添加标签 {#tagging-wiki-pages}

标签在维基页面上的用法相同。查看或编辑维基页面时，页面内容下方会出现 **标签字段**。在这里添加和移除标签，操作与工作项一样。

<!-- screenshot: tag field on a wiki page -->

添加到维基页面的标签会以可点击的标签块显示在页面上，与作者和最后编辑信息并排。

## 点击标签块 {#clicking-a-tag-chip}

每个标签块都是一个 **链接**。点击后会打开[搜索页面](../issues/finding.md#search)，并已按该标签筛选，显示你有权访问的所有项目中带有这个标签的工作项和维基页面。想从一个条目跳到所有带相同标签的内容，这是最快的方式。

链接目标是 `/search/?scope=all&tag=<tag-name>`。这些 URL 可以加入书签。

## 在搜索中按标签筛选 {#filtering-by-tags-in-search}

搜索页面有专门的 **按标签筛选** 控件，与文本搜索框分开。

<!-- screenshot: tag filter on the search page -->

可以同时按多个标签筛选。选择多个标签时，结果按 **AND 逻辑** 计算：只返回带有 **全部** 所选标签的条目。

主要行为：

- **跨项目**：筛选范围覆盖你有权访问的所有项目（你是成员的项目或公开项目），而不只是当前项目。你不是成员的私有项目中的标签不在范围内。
- **不区分大小写**：输入 `backend` 可以匹配名为 `Backend` 的标签。
- **自动补全**：输入时，输入框会从你有权访问的项目中提示标签名称，设置了颜色的会一并显示。
- **可与文本查询组合**：文本搜索词和标签筛选可以一起使用，结果必须同时满足两者。
- **可不带文本查询**：只按标签筛选（不输入文本）时，会列出所有匹配的条目，按最近更新时间排序。
- **覆盖工作项和维基页面**：无论当前选中哪个范围选项卡，标签筛选始终同时搜索两者（把范围选项卡切换到“仅维基”时，只显示匹配的维基结果，其他选项卡同理）。

### 移除标签筛选 {#removing-a-tag-filter}

点击筛选栏中标签块上的移除按钮，即可取消选择该标签。页面会重新加载，并应用剩余的筛选条件。

## AI 智能体与标签 {#ai-agents-and-tags}

如果你通过 MCP 让 AI 智能体（AI agent）使用 Specivo，智能体拥有同样的标签操作能力。它可以：

- 列出项目的标签库（含使用数量）。
- 在工作项或维基页面上添加、移除标签或替换整组标签，也可以在创建工作项或维基页面的同一步中添加标签。
- 添加标签时随手创建新标签（取决于该成员的项目角色）。
- 如果账户拥有 `manage_project` 权限，还可以维护标签（创建、重命名、改色、删除）。

MCP 的 `specivo_tag` 工具接受一个工作项引用（例如 `ACME-42`）或维基引用（`wiki:ACME/some-slug`）、一个操作（`get`、`add`、`remove`、`set`），以及一个标签名称或名称列表。智能体最先阅读的设置指南会要求它们在添加标签前先查看已有标签，并且绝不把标签写进描述或页面正文。完整的工具目录见[智能体能做什么](../ai-agents/capabilities.md)。
