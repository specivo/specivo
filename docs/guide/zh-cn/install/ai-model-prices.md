# AI 模型价格 {#ai-model-prices}

Specivo 按 **API 价格** 计算 AI 使用的价值，也就是同样的 token 在服务商按量付费价目表上的花费。这些价格保存在一张表里，由管理员在 **管理 → AI 模型价格** 下维护。每个 Specivo 版本都附带数百个模型的标价，你也可以用任意已启用的[货币](currencies.md)添加自己的价格。

使用 Claude Max 这类包月套餐产生的用量，同样按这些价格计价，以便与套餐费用对比；套餐本身记录在 [AI 订阅](ai-subscriptions.md)中。

价格会随时间变动，因此这张表是一份 **历史**。每条价格都有一个有效期，用量始终按其发生时刻有效的价格计价。修改价格从不覆盖旧价格。

## 一条价格包含什么 {#what-a-price-holds}

所有价格均为 **每百万 token** 的价格，使用同一种货币。用量按 token 类别统计：

| 价格 | 适用于 |
|---|---|
| 输入 | 新输入的 token，不含缓存读取和写入 |
| 输出 | 生成的 token |
| 缓存写入（5 分钟） | 保留 5 分钟的提示词缓存写入 |
| 缓存写入（1 小时） | 保留 1 小时的提示词缓存写入。服务商未公布时，内置价格取输入价格的两倍。 |
| 缓存读取 | 提示词缓存命中 |
| 推理 | 与输出分开上报的推理（“思考”）token。留空表示与输出同价。 |

其他任何价格留空，表示该类 token **未定价**。含有这类 token 的用量会显示为*部分计价*，而不会当作这些 token 免费。`0` 是一个真实价格：免费。

### 长上下文 {#long-context}

有些服务商对携带长上下文（例如超过 200,000 token）的请求收取更高费用。一条价格可以包含一个 **阈值**，以及该档位的第二组价格。上下文（输入加缓存读取和写入）超过阈值的请求，**全部** 按长上下文价格计费；恰好等于阈值则不算。长上下文价格留空时，回退到同类的普通价格。

上报工具把这类请求的 token 放在单独的 `long_context_tokens` 桶里，与其他请求的普通 `tokens` 并列。两个桶从不重叠：每个 token 只按自己档位的价格计价一次，token 总数则把两个桶相加。

### 本地模型 {#local-models}

一条价格可以标记为 **本地模型**，并可选填一个 **基准模型**：用这个付费模型的价格为本地模型的用量计价，以显示本地运行节省了多少。

## 价格从哪里来 {#where-prices-come-from}

每条价格都有一个 **来源**：

| 来源 | 说明 |
|---|---|
| 内置 | 随本版本 Specivo 附带的价目表 |
| 管理员 | 由管理员在页面上或通过 API 录入 |

当内置价格和你录入的价格同时有效时，**以你的为准**。

### 内置价格 {#the-bundled-prices}

内置价目表来自 [LiteLLM](https://github.com/BerriAI/litellm) 的模型价格列表（MIT 许可证），只保留了编程智能体直接使用的服务商的文本模型：Anthropic、OpenAI、Google Gemini、xAI、DeepSeek、Mistral、Moonshot、Z.ai 和阿里云 DashScope。**内置价格** 卡片显示本版本包含多少个模型，以及该列表对应的日期。

LiteLLM 只发布 **当前** 价格，没有历史。因此内置列表以 **只追加** 的方式加载：

- 你的实例中新出现的模型，获得一条 **从列表日期起** 有效的价格。
- 价格未变的，不做任何改动。
- 价格有变的，内置时间段在新列表日期 **结束**，并从该日期开始一个新时间段。旧时间段保留，所以更早的用量仍按旧价格计价。
- 你录入的价格永远不会被改动，你停用过的内置价格也不会。

列表在安装 Specivo 时加载，之后每次 worker 启动时再次加载，所以带来新列表的升级会自动应用它。**立即加载内置价格** 可随时手动执行同样的操作。

某个模型第一个内置时间段 **之前** 的用量不会被计价：Specivo 从不用更晚的价格回填更早的用量。如果你需要那段时间的价格，请把它们录入为过去的时间段（见下文）。

## 查找价格 {#find-a-price}

列表默认显示 **当前有效** 的价格，每个模型和来源各一行。你可以按服务商、模型名或别名的一部分、来源，或状态（启用或已停用）筛选，切换到 **所有时间段** 还能看到过去的价格。点击某个模型可打开它的 **价格历史**：所有时间段，包括内置的和你录入的，最新的在前。当前正在使用的时间段标记为 **当前使用**。

### 模型名如何匹配 {#how-a-model-name-is-matched}

各工具上报的模型名格式不一。匹配前，Specivo 会：

1. 转为小写并去掉首尾空格；
2. 去掉 `anthropic/`、`openai/`、`google/` 或 `models/` 之类的服务商前缀（`Anthropic/Claude-Sonnet-4-5` 变为 `claude-sonnet-4-5`）；
3. 先查找同名模型，再查找把它列为 **别名** 的模型。

在用量发生时刻有效的价格中，模型名精确匹配优先于别名，你录入的价格优先于内置价格。如果当时没有任何有效价格，该用量 **未计价**。

## 修改价格 {#change-a-price}

价格从不就地编辑。修改价格就是 **从某一时刻起的新价格**：

1. 从列表中打开该模型。
2. 在 **新价格生效于…** 下，表单已填入当前价格。只改有变化的部分。
3. 把 **生效时间（UTC）** 设为新价格生效的时刻，然后保存。

你之前为该模型录入的价格在这一时刻 **结束**，新价格从此开始。两个时间段严丝合缝：变更时刻的用量按新价格计价，之前一刻的用量按旧价格计价。所有时间均为 UTC。

要为尚无价格的模型添加价格，或覆盖某条内置价格，在列表页使用 **添加价格**，输入服务商和模型。

### 录入过去的时间段 {#enter-a-past-period}

服务商迟迟才公布调价，或者你需要为内置列表日期之前的用量提供价格时，可以录入一个 **过去的时间段**：同时填写 **失效时间（UTC）**。过去的时间段不能与你为同一模型录入的其他价格重叠；请先结束或停用那条价格。

### 重新计算过去的使用 {#recompute-past-usage}

AI 使用在记录时就按当时有效的价格计价，并保留该价值：添加、结束或停用价格都不会改变已记录的用量。如果你刚录入的价格起始于过去，而其时间段内已有记录的用量，该模型页面会显示 **重新计算过去的使用**，并给出条目数和范围。点击 **重新计算这些条目**，即可在后台重新计价。每条记录按自己的时刻计价，所以调价前后的用量各按所属时间段的价格计算，绝不会简单套用最新价格。价值发生变化的条目会生成新的修订版本，[审计日志](audit-log.md)则记录一条 `ai_usage_costs_recomputed` 事件，包含前后总额。

通过 API，管理员可以用 `POST /api/v1/admin/ai-usage/recompute/` 重新计算任意范围，请求体形如
`{"from": "2026-01-01T00:00:00Z", "to": "2026-06-01T00:00:00Z", "provider": "anthropic", "model": "claude-opus-4-6"}`
（provider 和 model 可选；model 也会匹配其别名）。接口返回 `202`，附带任务 id 和该范围内的条目数。

### 其他货币 {#other-currencies}

一条价格可以使用任意已启用的货币，例如为按人民币计费的服务商选 CNY，或为合同价选 EUR、THB。用量随即以该货币计价，报表再用[汇率](exchange-rates.md)换算，与其他金额一样。

## 结束、停用或删除价格 {#end-deactivate-or-delete-a-price}

在价格历史中某个时间段的 **详情** 下：

- **保存结束时间** 设置或清除该时间段的结束时间。清除后时间段重新开放。
- **停用** 让价格不再参与计价但不删除；**启用** 将其恢复。
- **删除** 移除你录入的价格。内置价格不能删除（下次加载会再回来），请改为停用。
- **别名** 和 **备注**（例如服务商公告的链接）可随时编辑。

一旦有用量用某条价格计过价，该价格就 **不能删除**，其结束时间也不能移到该用量之前。请改为停用。它的金额和开始时间永远不能更改：请录入一条新价格。

## 通过 API {#through-the-api}

页面上的所有功能，管理员都可以在 `/api/v1/admin/ai-model-prices/` 下通过 API 使用。价格是形如 `"3.75"` 的十进制 **字符串**，绝不是 JSON 数字；时刻需要带时区偏移（`2026-06-01T00:00:00Z`）。

```bash
# Prices valid at an instant (given here in Asia/Bangkok time)
curl -H "Authorization: Bearer $TOKEN" \
  "https://specivo.example.com/api/v1/admin/ai-model-prices/resolve/?model=claude-sonnet-4-5&at=2026-11-06T09:00:00%2B07:00"

# A new price from an instant: ends your previous price of the model there
curl -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  https://specivo.example.com/api/v1/admin/ai-model-prices/ \
  -d '{"provider": "anthropic", "model": "claude-sonnet-4-5", "currency": "USD",
       "prices": {"input": "3", "output": "15", "cache_write_5m": "3.75",
                  "cache_write_1h": "6", "cache_read": "0.3"},
       "effective_from": "2026-12-01T00:00:00Z"}'
```

`resolve/` 返回 `priced` 及对应价格，或返回 `unpriced`。其他端点：`GET /`（列表与筛选）、`GET /history/?provider=&model=`、`GET /providers/`、`GET`、`PATCH` 和 `DELETE /{id}/`，以及用于加载内置列表的 `POST /seed/`。

每次修改都会写入[审计日志](audit-log.md#ai-model-prices)。

## 离线部署 {#air-gapped-installs}

内置列表是镜像的一部分，不会下载任何内容。按需手动录入或更正价格即可。
